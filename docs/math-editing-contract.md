# 数学公式实现契约（#20）

依据 [#20](https://github.com/HoboCY/CueNote/issues/20) 与已确认的 Q50/A25。沿用原生 v1 的 `mathInline { latex }` 和 `mathBlock { latex }`，不改变文件格式版本。内容区支持公式；线索与总结继续使用精简排版。

## 编辑与保存

支持 `$...$` 行内公式和独占行 `$$` 围起的公式块，以及明确的插入、点击修改源码入口。确认修改作为正文中的一次撤销操作；取消不改变正文。保留原始 LaTeX 和节点类型，不把渲染 HTML 或图片写入原生文档。

转义美元符号、行内代码和代码块中的美元符号不触发公式解析。打开已有文档时只呈现已有公式节点，不扫描普通文字并改变内容。表格的行内节点能力与原生格式一致。

逐字输入时，未闭合反引号后的 `$...$` 暂不自动转换，以保留随后闭合为行内代码的可能；字面反引号可转义，也可用工具栏插入公式。

语法错误、不支持的命令和超出显示限制的公式保留可编辑源文本并显示提示，不作为文档转换错误，不阻止其他内容编辑、自动保存、手动保存及重开。原生文件与文字投影保留公式源文本；全文搜索和 Markdown 导出分别在 #25、#30 验证。

## 离线显示与资源保护

使用已选定的免费开源 Tiptap Mathematics 与 KaTeX，锁定兼容版本。脚本、样式和字体随应用打包；禁止公式加载外部资源，不提供完整 LaTeX 文档编译或任意宏包。

组件接口依据 [Tiptap Mathematics](https://tiptap.dev/docs/editor/extensions/nodes/mathematics)，限制配置依据 [KaTeX options](https://katex.org/docs/options) 与 [security](https://katex.org/docs/security)。输入语法及后台渲染由应用适配，避免直接采用组件默认的输入分隔符或主线程排版。

渲染限制覆盖输入与打开文件两个入口，且只影响显示，不删改源文本。采用独立渲染工作线程和有界任务，超时或超限回退为源码提示。初始显示预算：单公式源码 16,384 个 UTF-16 单元、花括号嵌套 64 层、宏展开 256 次、尺寸 20 em；线程就绪后单次排版最多 500 ms，启动最多 3 秒；排队与执行中的任务合计最多 128 个；单公式 HTML 最多 131,072 个 UTF-16 单元，当前编辑器存活的公式 HTML 合计最多 2,097,152 个。超过预算仍保留完整原生源码，正文仅显示有界预览。

KaTeX 每次使用新的宏表；不信任外部资源与 HTML 命令，拒绝时显示提示。Tiptap Mathematics 锁定 3.31.4，KaTeX 锁定 0.18.10；安装时排除了 npm 标为弃用且有破坏性变更的 0.18.11，不升级其他编辑器组件。
