# 自动保存、关闭保护与恢复草稿（#15）

依据 [#15](https://github.com/HoboCY/CueNote/issues/15)、已批准的保存规则与 A09/A16/A17/A18。原生文件格式、资源预算、安全发布和每篇最近 30 份普通历史沿用 [首篇笔记实现契约](note-storage-contract.md)。本文记录实现契约；验证结果另行记录，不以设计描述代替通过证据。

## 保存与离开编辑页

停止输入约一秒后自动提交快照；中文组合输入完成前不提交中间文本。手动保存、自动保存、切换和关闭使用同一个串行保存队列。一次保存成功只确认发送的快照，期间新增的编辑仍待保存，不能被旧响应覆盖。

切换或关闭会等待正在进行的保存，再保存后续编辑。等待时可以取消离开；取消不撤销已开始的磁盘写入。失败或冲突留在编辑页，保留当前文字并显示实际原因，不显示“已保存到本机”，不进行无间隔的自动重试。明确放弃修改属于用户选择，不能由错误处理自动代办。

Rust 同时拦截窗口关闭与应用退出。前端必须先订阅关闭请求并成功激活保护，才能开放编辑；完成等待后通过受限命令批准退出。前端不获得任意文件系统、进程退出或窗口销毁权限。应用退出事件与窗口关闭事件是不同入口，参见 [Tauri RunEvent](https://docs.rs/tauri/2.12.3/tauri/enum.RunEvent.html)；Mac 事件接入不代表 Mac 实机已通过。

## 可持久化的恢复快照

每次保存尝试先在同步目录之外的本机恢复区写入完整快照：独立临时文件、同步、重读校验、无覆盖发布为草稿文件、同步目录。只有这些步骤成功后，才继续写笔记目录中的候选文件并执行原来的版本核对、旧版保留与安全发布。

正常发布且确认目标可读后，只处理本次创建的精确草稿。失败、中断和旧失败草稿不参与普通历史轮换；发布后、清理前中断可能留下重复但完整的快照，不能为避免重复而自动清理未确认处理的版本。恢复区失败时停止原位置保存并如实报告，界面仍保留草稿，用户可选择其他位置另存。

恢复列表兼容既有 `drafts/<noteId 的 SHA-256>/draft-UUID.cuenote`，每个条目都重新校验包、身份和内容指纹。坏文件保留并警告，不遮蔽其他有效草稿；恢复目录整体不可达必须报错。恢复标识绑定已验证版本，前端不能提交任意读取路径。列表时间是草稿文件的落盘时间，不冒充笔记内容修改时间。

“恢复为新笔记”保留完整内容与资产，分配新笔记身份，放入当前库的默认笔记本。新文件成功落盘并重读后才处理选中的草稿，原笔记和其他版本不变。这是失败草稿的找回入口；完整外部冲突处理仍由 #23 实现。

## 安全另存

原生文件选择器授权一个新文件路径，取消不写文件。另存用独立身份保存完整原生副本，拒绝覆盖已有文件，也不写入当前库或恢复区；使用同目录候选校验、无覆盖原子创建和重读验证。它不依赖已经故障的默认恢复区，不能退化为直接覆盖。

另存当前草稿成功只确认该份副本，不能改变原笔记的保存基线或把原位置标成已保存。用户可继续编辑、重试原位置，或明确放弃原位置的修改后离开。恢复列表里的完整草稿也可另存，供当前库不可用时取回数据。

## 已批准的验证边界

沿用任务中明确要求的公开接口：保存协调器的编辑/保存/等待行为、Rust 保存与恢复接口、真实桌面操作。时钟及 IPC 边界可用于前端时序测试，真实存储用隔离目录；这些单独的检查不能代替真实桌面端到端验证。

`storage-fault-injection` 是显式启用的调试功能，正常构建不读故障环境变量，发布构建即使启用该 feature 也不会执行注入。注入要求绝对隔离根 `CUENOTE_FAULT_ROOT`，只有目标与候选均位于该根下才生效，且每进程至多触发一次。`CUENOTE_FAULT_STAGE` 选择以下边界，`CUENOTE_FAULT_ACTION` 选择进程退出、I/O 错误、模拟空间不足、候选损坏或等待测试放行：

- `recovery_snapshot_persisted`：恢复快照已经同步和校验。
- `candidate_created`：候选刚创建，可模拟只写入四字节 ZIP 前缀。
- `candidate_synced_before_validation`：候选已同步，尚待实际读取校验。
- `candidate_validated`：候选通过校验。
- `history_persisted`：旧版已保留。
- `publish_before` / `publish_after`：原子发布前后。

测试父进程必须观察到阶段标记，并核对退出码、重新打开的原件、恢复列表及恢复出的独立文件。标记本身不是保存成功证据。空间不足属于受控错误注入，未实际填满用户磁盘；进程退出测试不等于突然断电认证。只读、文件占用及目录不可达另用真实隔离文件系统操作检查。

已显示本机保存成功的内容、已持久化恢复快照和契约要求保留的有效版本须能重新读取。尚未落盘的最后输入不承诺在强制结束进程或断电时零丢失。Mac、真实 OneDrive、整库备份及最终日用验收仍由对应任务验证。
