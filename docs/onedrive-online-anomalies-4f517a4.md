# 真实 OneDrive 在线异常文件保护

2026-10-20，Windows 普通安装版 `3518441` 与 M1 Pro 普通安装版 `4f517a4` 完成损坏包、未来格式和缺失图片三个 A15 子场景，独立核对 **53 项通过，0 项失败**。随后 Windows 真实云占位文件补测新增 **13 项通过，0 项失败**。结合已有外部删除保护，A15 调整后的在线范围已通过；用户取消的实际离线/断网部分仍未验证，不计作完整原规格通过。

三个样本均从已有合成笔记生成，使用新身份，并保留有效原件及异常版本。只在 Windows 的专用 OneDrive 测试库发布，通过真实 OneDrive 送达 Mac；没有直接复制到 Mac 同步目录，也不将构造异常文件说成原生编辑。

Mac 初次收到的三个文件均为真实 `compressed,dataless` 占位文件。应用先提示下载完整笔记库，并说明不会当作空白内容保存。随后用系统只读文件操作完成下载，再由普通应用检测到上述三种具体原因。系统读取触发下载不等于应用自身已实现下载操作。

两端均通过原生按钮再次检查文件更新。列表保持三个有效笔记，异常包没有变成可编辑空白笔记。10 份事实文件在两端逐字节一致；原有三篇笔记及四份笔记本元信息均未改变。异常样本归档后已从测试库清理，清理通过真实 OneDrive 传播，两端恢复原有七份事实文件，哈希与测试前一致。

Windows 证据为 `windows-a15-faults-720`、`windows-a15-recheck-721`、`windows-a15-cleanup-722`；Mac 原生队列为 763–775，其中 770 是占位提示，771/773 是下载后提示，774 是清理后界面。764 因辅助脚本键名错误退出，保留失败记录，不计入通过；766 使用正确键名完成导航。

Mac 原始证据归档 SHA-256：`5b97486fc93be773588c601fe93a3009ac688635b7e2155b89c56f938d215357`。归档、合成文件、两端快照及独立核对脚本保存在本机 `implementation-execution/issue-33/mac-management-4f517a4/`。原始截图不公开。测试队列已停止，本轮唯一新建的测试终端已关闭，原有终端保留。

本轮不涉及产品源码修改；结果与范围见[机器可读记录](onedrive-online-anomalies-4f517a4-results.json)。已有外部删除保护结果继续复用，不以此次检查替代其恢复证据。
