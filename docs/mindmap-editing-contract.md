# 思维导图实现契约（#22）

依据 [#22](https://github.com/HoboCY/CueNote/issues/22)、[首版最终规格](https://github.com/HoboCY/CueNote/issues/8#issuecomment-6165724793) A08/A10/A23，以及既定 Tauri/Tiptap/Mind Elixir 架构。

## 内容与文件

思维导图是内容区顶层内容块，与段落、图片保持同一顺序。使用已有 v1 `mindMap { mapId, rootId, nodes }`：每个节点保存 UUIDv4、原始文字和有序子节点标识。文件不保存 Mind Elixir 私有属性、DOM、预览 URL 或编辑历史。节点文字包含的空白、空字符串、换行和 Unicode 不应被编辑组件静默改写。

单篇所有导图共用 5,000 节点上限。前端转换检查结构和总量，Rust 的完整候选预检与实际保存复用同一文件格式校验。检查失败不得修改此前有效草稿或原文件；读入同样执行格式预算。500 节点样本用于本任务的功能压力验证，正式双平台性能验收仍由 #31/#33 汇总。

## 编辑、历史与保存

插入发生在当前段落或其所属顶层内容块之后，保留前后文字。导图可上移、下移、删除；点击预览进入展开编辑。展开编辑使用固定版本 Mind Elixir 5.15.1（MIT，许可证见同目录 licenses），仅开放原生结构能够保存的节点文字和层级能力。

展开期间正文保留展开前的编辑器历史基线，已接受的导图修改实时进入完整笔记草稿，参加原有自动保存、失败保护、另存、切换和关闭流程。未失焦的节点输入以及中文组合输入必须在快照稳定后再完成手动保存或离开。异步预检结束时复核当前会话和草稿，过期结果不能覆盖较新的内容。

导图内部撤销和重做只影响该导图；收起时将本轮导图编辑作为一次正文历史变更写回，更新预览，返回原导图位置和展开按钮焦点。导图只读预览不暴露修改入口，权限切换不依赖额外正文事务来更新控件。

## 已确认的验证边界

- 模型转换与真实编辑器事务：完整文字和边顺序、插入移动删除、独立撤销、收起后的正文撤销重做、失败与过期操作。
- 公开 Workspace 与真实隔离文件：混合图片和导图保存重开、独立副本、恢复、预算边界、拒绝后的原件与会话不变。
- Windows 真实桌面窗口、宿主和磁盘：小图创建编辑、展开状态保存、收起预览、退出重开继续编辑，以及 500 节点样本。

本契约不是实测通过声明；结果单独记录。Mac 与真实 OneDrive 的最终日用验收属于 #33。
