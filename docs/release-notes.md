CueNote 是采用康奈尔布局的本地笔记应用，支持富文本、图片、公式、代码块和思维导图。

## 下载与安装

| 系统 | 下载附件 | 安装方式 |
| --- | --- | --- |
| Windows x64 | `CueNote_*_x64-setup.exe` | 运行安装器，仅安装给当前用户 |
| Apple Silicon Mac（M1 及更新芯片） | `CueNote_*_aarch64.dmg` | 打开 DMG，将 CueNote 拖到“应用程序” |

Mac 包的最低系统配置为 macOS 14.0，CI 在 macOS 15 上验证；不包含 Intel Mac 安装包。
Windows 缺少 WebView2 时，安装器需要联网获取 Microsoft 运行时。

## 首次打开

**Mac：此包使用 ad-hoc 签名，未经过 Apple 公证。**

1. 安装后，从“应用程序”打开一次 CueNote。
2. 若出现无法验证开发者或 Apple 无法检查恶意软件的提示，关闭提示。
3. 确认下载来源后，打开“系统设置 → 隐私与安全性”，找到 CueNote 的阻止记录，点击“仍要打开”。
4. 根据系统提示认证并确认打开。

公司管理的 Mac 可能禁止手动允许。若提示应用已损坏或将损坏电脑，请停止打开并反馈具体提示。
操作依据：[Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows：安装包未进行代码签名，可能出现 SmartScreen 来源提示。**
确认从本仓库下载后，可在系统提供该选项时通过“更多信息 → 仍要运行”继续。

## 更新和数据

应用没有自动更新器。Windows 用户退出 CueNote 后运行新版安装器；Mac 用户退出后替换旧应用。
卸载仅删除程序，保留笔记库、配置、恢复草稿与备份。请将笔记库放在应用安装目录之外。
第三方依赖许可随安装包附带。

## 验证范围

Release 上传附件仅包含 Windows 和 Mac 安装包。发布前，两端均需通过构建、测试及八阶段
安装、启动、升级、卸载与重装检查；详细校验和构建记录保留在 GitHub Actions 中。
这些 CI 检查不能替代用户实际设备上的首次下载打开、系统权限和 OneDrive 同步验证。
