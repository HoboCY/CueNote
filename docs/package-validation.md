## 诊断与修正依据

- 本机默认 NSIS 工具缓存的重命名返回 Windows error 17；使用官方
  `useLocalToolsDir` 后成功构建，未移动或清理用户系统缓存。
- [首轮 CI](https://github.com/HoboCY/CueNote/actions/runs/39041481800)拒绝了
  12 个未附带许可证文件的 Objective-C crate。按锁定提交补齐上游声明及 MIT
  原文，保留作者信息；同时为生成契约设置 `eol=lf`，解决 Windows 新检出
  CRLF 与生成器逐字节校验不一致的问题，没有改变契约内容。
- [上一轮 CI](https://github.com/HoboCY/CueNote/actions/runs/39042235350)的 Mac
  全部通过，Windows 升级后的程序哈希不匹配。解包比对确认只有 Tauri 临时修改
  bundle 类型标记的 3 字节差异；锁定 bundler 源码证实打包后恢复原文件。
  应用没有自动更新器，使用官方 `--no-binary-patching` 后，本机解包及最终 CI
  均证明安装后的程序与回执完全一致，未放宽哈希要求。
- age 1.3.2 工具归档摘要核对、加解密往返、错误密钥和篡改密文拒绝均通过。
  私钥仅在本机仓库外，文件 ACL 限当前用户；CI 只使用公钥。
