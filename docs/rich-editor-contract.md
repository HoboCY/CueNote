# 三分区富文本与 Markdown 实现契约（#18）

依据 [#18](https://github.com/HoboCY/CueNote/issues/18) 与 [最终验收规格](https://github.com/HoboCY/CueNote/issues/8#issuecomment-6165724793)。本任务沿用原生格式 v1；代码、公式、图片和导图编辑依次由 #19–#22 交付。

## 文档与保存

Rust 的 `Document`、`Block`、`Inline` 和原生校验器继续作为文件格式权威。编辑器 JSON 通过显式双向转换进入应用模型，不写入文件协议。新增 `NoteContent` 仅包含标题与三个分区；会话身份、笔记身份、组织信息、时间、资产与保存版本基线仍由宿主管理。

`save_note_content` 和 `save_current_content_as` 接收会话 ID 与完整内容快照。前者继续使用安全保存与失败草稿机制；后者保存独立身份的完整副本，不将原会话标为已保存。原有纯文本入口保留其禁止覆盖富内容的检查。自动保存回执更新已保存基线，不能覆盖期间的新输入，也不能重建编辑器或清空撤销记录。

正文可编辑段落、1–3 级标题、加粗/斜体/删除线、有序/无序/任务列表、引用、链接、分隔线和基础表格。线索和总结仅允许文字、加粗、列表、简单标题与换行。链接遵循原生格式允许的 HTTP、HTTPS、mailto 协议。表格固定首行为表头，其他行为普通行，行列数一致；单元格保存行内内容，不支持合并、嵌套表格或电子表格计算。

未知节点、标记或无法表达的结构必须显示错误并停止编辑，不能先丢弃再保存。当前未提供编辑器的已知 v1 内容只读显示；完整结构与资产仍由宿主保留，可另存完整副本。打开既有内容不能因编辑器的空段落或默认属性产生自动保存。

## 交互

每个分区拥有独立编辑器和撤销历史。仅实际切换笔记会话时重建，重启后无需保留撤销历史。Ctrl/Cmd+Z 交由当前编辑区处理；全局快捷键不能拦截方向键或中文组合输入。组合期间暂停自动保存，完成后提交最新完整快照。

编辑区提供 Markdown 输入提示与工具栏；表格通过工具栏创建并增删行列。康奈尔 A 布局保持约 28/72 的线索/内容初始比例，底部总结与全文连续滚动。工具栏和侧栏操作保留当前内容与编辑区选区，保存回执不移动光标。

## 验证边界

沿用已确认的原生模型、Workspace 保存/恢复和真实 UI→宿主→文件→重开边界，并落实 #18 明确要求的编辑器转换校验：

- 模型转换：以明确的基础节点样本检验转换与拒绝行为，包含表格和列表结构；不能代替实际键盘交互。
- Workspace 与文件：完整节点保存、重开、身份与组织信息不变，非法结构、旧基线和不支持内容不得覆盖原件；失败草稿与独立副本仍保真。
- Windows 桌面：真实分区输入、排版、表格操作、分区撤销、侧栏切换与保存重开；区分合成组合事件与用户真实输入法体验。

Windows 的自动验证不作为 macOS 或真实 OneDrive 验收；两台实机的最终结论由 #33 汇总。
