# 笔记本与列表实现契约（#16）

依据 [#16](https://github.com/HoboCY/CueNote/issues/16)、[组织规则](https://github.com/HoboCY/CueNote/issues/2#issuecomment-6104384225)及既有原生文件契约。本项实现 A01/A02 和 A05/A14 中本机导航、组织持久化的部分，不代替后续回收站、外部更新、OneDrive 和双端验收。

## 用户行为

- 笔记本不嵌套。自建本名称去除首尾空白后须非空且不重复；默认本不可删除。仍有正常笔记的本须先移动笔记或在后续回收站功能中处理，不能直接删除。
- 全部笔记中新建归默认本；单本中新建归当前本。空标题显示“未命名笔记”，同名笔记凭稳定身份独立保存，列表显示摘要和内容修改时间。
- 列表先显示置顶笔记，两组内部均按内容修改时间倒序，时间相同用稳定身份确定顺序。打开、移动、置顶不改变内容修改时间；组织变化只更新组织时间。
- 重启打开上次编辑笔记；文件已不存在时回到列表，不创建替代空文件。侧栏收起与列表范围属于本机偏好。
- 切换或组织操作涉及当前草稿时，复用 #15 的保存会话与取消机制。界面筛选列表和收起侧栏不丢弃当前编辑内容。

## 事实文件与宿主接口

空笔记本依靠 `notebooks/<ID>.json` 独立存在。笔记归属和置顶仍保存在原生 `.cuenote` 包的组织字段中；界面不能提交任意磁盘路径、身份或时间。组织操作由宿主复制完整已校验文档和资产，经现有保存保护发布，不将富内容转换成纯文字。

宿主提供笔记本新建、重命名、删除，指定本新建笔记，当前会话组织更新及本机视图偏好接口。删除前必须确认没有正常笔记，无法读取文件不能被当作空本证明。无效参数或发布前失败不能先改变活动会话。如果保存报告错误，但独立回读确认目标文件与完整候选一致，则同步会话版本并显示后续步骤错误的提示；目标不可读或不一致时仍返回原错误，不把外部版本采纳为本次保存结果。

本机设置继续使用独立快照，记录库路径、上次笔记和视图偏好；不写入同步事实目录。既有设置缺少新增可选字段时按默认值读取。

## 验证范围

沿用已批准的宿主工作区/文件接口和真实桌面 UI→宿主→磁盘→重开范围。每个新增行为通过公开工作区接口按失败测试→实现→通过推进；既有原生包读取器用于独立核对身份、内容、时间和资产保真。

真实 Windows 桌面检查覆盖命名规则、不同入口归属、摘要时间、移动置顶、重启定位、侧栏偏好及带草稿切换。普通浏览器替身、纯类型检查或仅磁盘测试都不作为桌面交互通过的证明。最后分别核对 Standards 与 Spec，并记录未测平台与剩余限制。
