# Domain docs

采用 single-context 布局：

- 根目录 GLOSSARY.md：领域术语。
- docs/adr/：架构决策记录。

## 探索前读取

探索代码前，读取已有的 GLOSSARY.md，以及与当前任务相关的 ADR。
文件不存在时直接继续，无需预先创建空文件。
领域术语或决策明确后，由 domain-modeling 按需创建文档。

## 术语一致性

任务、设计、代码和测试中的领域概念使用 GLOSSARY.md 定义的名称。
遇到未收录的概念，先核实项目既有用语，再判断是否需要补充。

## 决策冲突

建议与已有 ADR 冲突时，明确指出对应 ADR、冲突内容及重新讨论的理由。
