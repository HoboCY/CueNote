# 行内代码与代码块实现契约（#19）

依据 [#19](https://github.com/HoboCY/CueNote/issues/19) 与已确认的 Q50/A26。沿用原生 v1 的 `code` 标记及 `codeBlock { language, code }`，不改变文件格式版本。

## 编辑与呈现

代码功能只在内容区开放，线索与总结继续使用精简排版。提供反引号行内代码、带可选语言标记的围栏代码块输入，以及工具栏入口；代码块可选择七种验收语言或填写自定义语言标记。未知语言保持原标记并显示纯文本。切换语言只改变语言字段，不能重写代码。

JavaScript、TypeScript、Python、Rust、C#、SQL、JSON 的高亮随应用离线打包。采用已确定的免费开源 [CodeBlockLowlight](https://tiptap.dev/docs/editor/extensions/nodes/code-block-lowlight) 与 [lowlight](https://github.com/wooorm/lowlight)，按需注册语言；高亮仅为显示装饰，不写入文档或替换源码。

保留 Tab、空格缩进、空行、中文注释、HTML、美元符号和反引号。代码块内的输入与粘贴作为文字处理，不能触发列表、富文本或公式转换，也不能执行代码或 HTML。连续空行仍属于代码；离开代码块有明确操作。语言变更、输入和撤销沿用正文的独立编辑历史与自动保存边界。

## 保存与后续功能

编辑器转换保留代码原文和可空语言字段；有效但未知的语言不是转换错误。完整 `NoteContent` 经已有 Workspace 保存、失败草稿和安全另存路径落盘，重开后继续编辑。其他尚未接入的原生节点仍按既有只读保护处理。

既有 `NotePackage.text_projection()` 提取代码正文和行内代码原文，保留其中的空白和标点，不包含高亮 HTML；区块间分隔沿用已有文字投影规则。这个公开契约供 #25 全文搜索使用；#30 Markdown 导出另行验证围栏和附件，本任务不宣称已交付搜索或导出。

## 验证边界

沿用已确认的模型转换、公开 Workspace/原生文件及实际 UI→宿主→文件→重开边界，按 #19 明确的代码保真验收扩充样本：

- 编辑器转换和真实编辑器事务：代码文本、语言及标记往返；正文与精简分区的边界；高亮不改变文档，未知语言无猜测高亮。这不代替真实输入与粘贴。
- Workspace 与原生包：完整代码保存、重开、另存及原文投影；格式版本与其他不支持内容的保护保持。
- Windows 桌面：Markdown 输入、语言选择与修改、七种语言及未知语言、特殊字符和缩进、代码内不转换、编辑撤销、正常关闭重开。

Mac 与真实 OneDrive 双端日用由 #33 汇总，Windows 自动验证不作为双端验收。
