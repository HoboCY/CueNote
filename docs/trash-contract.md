# 回收站实现契约（#17）

依据 [#17](https://github.com/HoboCY/CueNote/issues/17)、[组织规则](https://github.com/HoboCY/CueNote/issues/2#issuecomment-6104384225)及既有原生文件契约。本项实现 A04 与 A14 的本机回收站部分，沿用此前已确认的 Workspace/原生文件公有接口和真实桌面 UI→宿主→磁盘验证范围。

## 用户行为

- 普通删除先完成当前草稿保存，再将完整笔记移入回收站。软删除写入原 `.cuenote` 包的 `organization.trashedAt`，只更新组织时间，保留内容时间、身份、原笔记本、置顶和全部资产。
- 正常列表与回收站分开。回收站按删除时间倒序展示，只读查看，恢复后才编辑；不自动清空。未来全文搜索以正常笔记集合为输入，不混入回收站。
- 原笔记本存在时恢复到原本；原本不存在时要求用户明确选择现有目标，不能自动归入默认本。只有回收站笔记的自建本允许删除，笔记中的原归属仍保留到恢复时处理。
- 永久删除需针对当前选中笔记单独确认；取消不调用删除接口。操作按会话身份和版本定位精确文件，删除此库中的该笔记包及内含附件，不按标题匹配，不递归清理目录，也不删除其他笔记、独立备份、历史或恢复副本。
- 软删除、恢复和确认删除的失败显示实际原因。发布已发生时须同步会话并说明后续失败，不能显示旧状态；发布前或版本冲突失败保留原件和当前会话。重启保持事实状态，已删除的上次编辑笔记回到列表。

## 宿主边界

`LibraryView` 的 `notes` 只含正常笔记，新增 `trashNotes`。两类摘要使用独立的内容时间 `modifiedAt` 与可空删除时间 `trashedAt`；`NoteSession` 同样增加 `trashedAt`。`open_note` 可打开回收站项，但宿主强制只读且不将它记为上次编辑笔记。

三个命令只接受不透明会话身份：`trash_note(sessionId)`、`restore_trashed_note(sessionId, targetNotebookId?)` 返回保存回执；`delete_trashed_note(sessionId, confirmed)` 返回更新后的工作区及空活动会话。未明确确认时拒绝永久删除，且不读取或修改目标文件。界面无任意路径读写权限。

组织写入复用完整候选校验、版本检查与安全保存；永久删除前重读并核对笔记身份、回收站状态和会话版本，拒绝非普通文件及库外路径。已成功解析的回收站文件不计入笔记本正常笔记数；不可读或损坏的文件不能作为空本证明。

## 验证范围

按行为逐项红→绿验证软删除/重启、恢复到原本及缺失原本、只读保护、同名不同身份隔离、完整包资产保真、取消和显式确认、文件占用及外部版本变化。真实 Windows 桌面通过点击、输入和确认流程触发，使用原生包读取器核对保存内容与组织状态；宿主测试通过不替代桌面操作证据。

本项不宣称完成跨进程删除竞态、OneDrive 双端同步或 macOS 实机验收；对应后续任务仍须覆盖这些场景。永久删除不是对独立副本进行安全擦除的承诺。
