# 库外笔记约定

对应 [#29](https://github.com/HoboCY/CueNote/issues/29) 和首版规格 A21。

## 打开与原路径保存

“打开库外笔记…”使用系统文件选择器选择独立 `.cuenote` 文件。不必先选择笔记库，也不会自动创建笔记库或把文件加入当前库。界面显示“库外笔记”和原文件路径；自动保存、手动保存及关闭保护沿用现有编辑流程。

路径由宿主选择、解析和缓存。前端只能提交会话 ID 与内容，不能将显示路径作为文件访问授权。会话明确区分库内笔记、库外文件和保留版本预览；库内移动、置顶、回收站和永久删除命令拒绝库外会话，即使两份文件的笔记 ID 相同。

打开时检查原生格式、资源预算及父目录的安全发布能力。原路径保存保持笔记 ID、原有组织信息和资产字节，复用恢复快照、版本基线检查与原子发布。文件被其他程序改动、删除或暂时不可读时，沿用历史与冲突保护；不重建空白原件。预览保留版本后，可以通过宿主保留的授权返回库外原文件。

当前库、本机设置、恢复和配置的备份目录不能作为库外原路径编辑目标。可识别的其他笔记库或备份快照目录（含 `notes` 与 `notebooks`）也须从对应笔记库或恢复入口访问；需要独立编辑时先另存独立文件，避免绕过整库恢复锁或改写不可变快照。带回收站标记或当前编辑器不支持的内容以只读方式显示，可保留完整内容另存副本。

## 另存独立副本到笔记库

选择目标笔记本后，操作先暂停待执行的自动保存，等待已经开始的保存、中文输入法、图片和导图编辑整理完成，然后直接复制当前编辑快照。它不调用“先保存原件”的切换流程。点击前已经开始的原路径保存仍会完成；本次副本操作不另行写回原文件。

宿主验证目标笔记本及其元数据基线，赋予新笔记 ID 和目标归属，清除置顶、回收站状态，并无覆盖创建新的原生文件。三分区、公式源码、代码、图片与可编辑导图全部保留。回读确认后才切到库内副本；失败保留原会话和草稿。两篇笔记之后独立编辑。

尚未选择笔记库时，可以先原路径编辑；要另存入库，先选择笔记库，再打开该库外文件。选择器取消或文件打开失败不替换当前会话。切换其他笔记、笔记库或关闭应用仍经过既有草稿保护。

## 搜索与备份范围

当前笔记库的列表、全文搜索和整库备份只包含库内事实文件。库外笔记可以拥有自己的本机历史和恢复草稿，但不会因此进入库内搜索或整库备份。编辑库外文件时仍刷新当前库的列表与搜索；入库后仅新副本进入其范围。

本项不增加文件格式版本、操作系统文件关联或跨设备同步协议。Windows/macOS 使用相同原生文件，Mac 与真实 OneDrive 双端验收继续由 #33 跟踪。
