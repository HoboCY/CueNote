# Markdown 导出约定（#30）

依据 [#30](https://github.com/HoboCY/CueNote/issues/30) 与 A22/A25/A26。右上角“导出 Markdown…”通过原生文件夹对话框选择位置，在该位置新建一个带时间和随机标识的独立目录，包含 `note.md` 与 `assets/`。标题、线索、内容、总结依次输出。移动时应保留整个目录。

## 内容与源码

普通排版使用 CommonMark/GFM：标题、粗体、斜体、删除线、链接、列表、任务列表、引用、分隔线与基础管道表格。容易与标记冲突的普通标点转义；标点或空白边界的文字标记使用行内 HTML 标签。阅读器需支持相应 Markdown 扩展及行内 HTML。依据 [GFM 规范](https://github.github.io/gfm/)，代码跨度会归一化换行，管道表格先处理管道转义，无法把所有原生字符串都无损放进行内语法。

代码块采用长于内部反引号连续段的围栏。通常的语言标记（包括未知语言）保留在围栏中；不能安全放入围栏的特殊标签作为可见原文显示。每个代码块另附 UTF-8 `.txt` 源码，以保留精确的 Tab、空格、CR/LF 和末尾是否有换行；Markdown 围栏所需的结构换行不改变该源码附件。普通行内代码使用动态反引号与边界空格；多行代码和表格中反斜杠紧接管道符的代码改为编号引用，在相邻正文提供可见源码和相对路径附件。

普通公式按原始节点类型使用 `$...$` 或独占行的 `$$`，不改写 LaTeX。表格内含管道符的公式移至表后，单元格保留编号与源码链接。分隔符冲突、多行行内公式、空公式等无法可靠表达的内容显示为带原始 `$`/`$$` 包装的 TeX 源码围栏，并附完整 `.tex` 原文。单美元行内公式中的美元符号（含 `\$`）也走该保真路径，因为阅读器对内部转义的处理并不一致。坏公式不会被删除或擅自修正；数学显示取决于阅读器。GitHub 自身的数学扩展也有[独立语法说明](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions)。

图片保留原始 PNG/JPEG 字节，用相对路径引用；Markdown 阅读器负责显示大小。导图生成离线 SVG 树形静态预览，按固定行数分页，保留全部节点文字；节点编号、上级编号与层级供跨页阅读。预览不嵌入脚本或外部资源，另附节点 JSON 原文。静态预览和节点附件不等于可重新导入的原生笔记，不提供在 Markdown 中继续编辑导图的能力。

## 会话与写入

导出先暂停待执行的自动保存并等待已开始的操作、图片粘贴、输入法与导图编辑整理完成，再取得当前会话的完整快照。不主动刷新源文件、不分配新的原生笔记身份、不修改会话的保存状态。已开始的保存会先完成；导出结束后恢复正常自动保存调度。库内、独立库外、保留版本及回收站只读预览都可导出；无法转换的初始只读结构使用完整宿主缓存。导出不是解除原生保存失败或丢弃草稿保护的依据。

前端只提交会话标识和内容，不提交任意文件路径。宿主在对话框返回后再核对会话，目标拒绝当前笔记库、设置、恢复、已配置备份目录及可识别的管理目录树。已有文件、目录或链接均不覆盖。

存储层沿用选择时固定的父目录句柄，在唯一暂存子目录内写完 `note.md` 与全部附件，逐文件同步并回读验证内容和完整集合，然后无覆盖地重命名整个目录。发布后再次核对目录身份、附件目录身份和全部文件才返回成功。发布前失败可能保留 `.cuenote-export-staging-*`；错误包含其位置。发布或后续校验不确定时保留可能出现的最终目录，明确报告未确认成功，不自动删除或重试覆盖。

Windows 固定祖先与子目录以阻止重命名；Unix 在父目录描述符下创建目录、创建文件和发布，并复核路径身份。Windows 不提供此实现可依赖的通用目录落盘保证；进程中断验证不等于断电持久性。导出成功也不保证用户或其他程序之后不会修改结果。
