# 单篇备份恢复

对应 [#27](https://github.com/HoboCY/CueNote/issues/27) 与最终规格 A20；整库恢复由 #28 承接。

## 身份与归属

从已校验的备份记录查看笔记，每个原生文件有独立的选择身份和内容版本。相同笔记 ID 的不同备份文件分别列出，不能按标题或列表位置替换选择。

恢复保留备份中的笔记 ID。当前库中该 ID 的规范文件存在且身份唯一时更新该文件；不存在时按原 ID 安全新建。当前库存在同 ID 冲突或路径身份不符时拒绝恢复，先处理冲突。恢复包含标题、三分区、图片资产、可编辑导图、公式和代码，以及包内置顶、回收站与组织信息。来源在回收站中的笔记恢复后仍在回收站，只读查看。

原笔记本在当前库仍有效时保留该归属，沿用当前共享笔记本名称；不回退其他笔记的分类信息。原归属缺失或有冲突时，用户必须明确选择一个当前有效笔记本；仅改此篇归属及组织修改时间。单篇恢复不创建旧笔记本、不改写笔记本元数据，也不恢复整库的空笔记本集合。

备份笔记列表同时提供经宿主核验的当前有效笔记本 ID。界面仅以这些 ID 提供恢复目标，不能因为列表中仍显示某个冲突笔记本就锁定原归属。确认后宿主再次核验磁盘状态；列表加载之后新增的冲突或文件变化会阻止写入。

## 先保护，后写回

界面先整理编辑器并完成当前草稿保存；失败或冲突时不发起恢复。准备完毕后暂时锁定编辑与导航，恢复过程中保留当前会话，失败时仍可继续处理。

宿主重新校验整份备份及所选笔记的内容版本和资产，把已校验的包保留在内存。随后捕获当前目标版本、当前会话以及目标笔记本信息，在后台成功生成一份当前库的完整手动备份。该恢复前备份不会参与自动轮换；备份失败则不进入原件写入。

发布前再次核对目标版本、身份唯一性、归属与会话。本进程期间的修改或取消会阻止进入发布阶段。开始安全发布后，取消不能回滚已发生的写入，界面须报告实际完成或错误状态。现有单篇安全保存负责候选校验、原件历史、文件锁、版本比较及原子发布；恢复后真实重新打开并比对完整原生内容，再替换编辑会话。

重新打开所得的新编辑会话先暂存，最后的内容、归属与本机设置检查全部通过后才成为当前会话。检查失败时保留原会话及其版本依据，让界面的会话 ID 和宿主继续一致，仍能保护草稿；磁盘上已经发布的恢复文件不因会话保留而被回滚。

外部并发写入由版本保护和保留副本处理，不声称获得跨设备事务。若写入后重开、归属复核或收尾失败，明确提示可能已经写入及恢复前备份位置，不盲目回滚覆盖新到达的外部版本。界面或备份列表刷新失败也不得被描述为原件未恢复。

## 验证范围

自动化检查使用公开 Workspace/BackupContext 与隔离真实文件，前端在宿主 API 和时钟边界验证协调；Windows 桌面另验证实际控件、磁盘及重启。通过结果记录在单独的验证文档中。真实 Mac、OneDrive 和双端日用验收仍由 #33 汇总。
