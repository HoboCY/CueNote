## 观察和输入

固定只读观察器仅编入 Mac 的 perf-acceptance 变体。随机回环端口和每次启动的
256 位凭据限制访问；不接受任意 JS、业务调用或写入操作。WKWebView 原生
callAsyncJavaScript 完成回调等待双 requestAnimationFrame 后再返回；结果包含
实际帧计数、窗口坐标及文档焦点。事件发送前和最终观察后均核对前台 PID。

Swift 驱动用原生 CGEvent 派发鼠标、按键和 Unicode 文本，外部单调时钟计时。
辅助功能权限不足即停止，无 DOM 输入替代。CSS 坐标按与 DOM 视口吻合的 WebView 安全区域
换算，不额外乘 Retina 缩放。当前显示器/窗口位置的真实输入、选区和滚动必须
先通过独立副本校准，再进入完整矩阵。此前 TCC 日志确认 SSH 请求归属
sshd-keygen-wrapper，图形启动请求归属 Terminal。用户启用 Terminal 辅助功能后，
