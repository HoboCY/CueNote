# CueNote 康奈尔编辑交互原型

用于讨论 [CueNote 的标题、康奈尔分区与多种内容如何协调编辑？](https://github.com/HoboCY/CueNote/issues/3)。这是独立原型分支上的临时演示，不是正式应用；尚未选定桌面壳、生产编辑器或保存格式。

## 打开

直接用现代桌面浏览器打开同目录的 `cornell-editor-prototype.html`，或者在此分支根目录运行：

```sh
node prototype/serve.mjs
```

打开 [本机原型](http://127.0.0.1:4173/?variant=A)。服务只监听本机；不联网下载资源，不读写笔记文件。若端口被占用，可设置 `CUENOTE_PROTOTYPE_PORT` 环境变量更换端口。

没有安装或构建步骤。关闭或刷新页面会恢复演示数据。请只输入试用内容。

## 比较的问题

三个方案保留顶部标题、左侧线索区、右侧内容区和底部总结区；通过底部浮动条或 URL 的 `variant=A|B|C` 切换。

| 方案 | 要比较的交互 |
| --- | --- |
| A：纸张式康奈尔 | 常驻分类及笔记列表，一张连续滚动的康奈尔页面 |
| B：专注写作 | 收起导航，突出正文，按需展开线索和总结 |
| C：工作台 | 横向笔记入口，线索与内容分别滚动，总结保持可见 |

在非编辑区域使用左右方向键也能切换方案。正在输入时，方向键保留给文字编辑。切换方案保留本次页面内的笔记草稿。

建议试用：修改标题及三个分区；从截图工具粘贴一张图片到内容区；展开思维导图、修改文字、增删节点和调整层级；返回正文继续记录；用较长内容比较三个方案的滚动方式。

窄窗口会隐藏导航或将分区上下排列；在非常窄的窗口中，C 的总结回到文档流中，避免覆盖正文。桌面窗口才是本轮主要比较对象。

## 原型边界

- 所有修改仅存在当前页面内存中。不存在真实的自动保存、备份、迁移或桌面应用集成。
- 富文本工具栏支持粗体、标题、有序和无序列表。这些按钮只模拟所见即所得编辑，本原型没有 Markdown 语法解析或源码编辑器，不验证导入导出、生产编辑器或跨组件撤销栈。
- 思维导图使用简化的可编辑树展示，未选定生产导图库。
- 图片预览采用浏览器临时对象地址，不代表附件已经保存。实际系统剪贴板来源与中文输入法仍需后续 Windows/macOS 验证。
- 分区编辑能力、比例、折叠、导图展开方式及是否需要 Markdown 源码模式均为待用户反馈的交互建议。
- 演示帮助与状态面板属于原型观察工具，不属于正式产品界面。

收到用户反馈后，在决策任务中记录确认的结论。本原型不直接合并到主分支。
