# 原型运行观察

日期：2026-10-11。环境：Windows、隔离配置的无界面 Microsoft Edge 155.0.4283.45。本记录只描述临时 HTML 原型；不代表 Windows/macOS 桌面应用验收。

## 已观察到的行为

- A/B/C 布局可通过按钮和 URL 切换；标题、线索、正文、总结的本次编辑保持在页面内存中。
- 切换到另一笔记本的样例笔记，再返回原笔记，草稿内容保留。
- 在文字编辑区域按方向键不会切换布局；在非编辑区域可以切换。
- 基础粗体按钮改变所选正文的格式。
- 导图根节点受保护；添加子节点、改名、缩进到上一兄弟下、提升一级及删除节点均改变可观察的树结构。关闭导图后焦点返回原来的展开按钮。
- 通过浏览器内构造的图片文件和粘贴事件，可以在正文的文字块后插入图片，图片成功解码，并可调整到 50% 宽度及移除。
- 1440 像素桌面宽度下三种布局以及 760 像素宽度的 A 布局没有页面级横向溢出；760 像素时可以找到导航按钮。
- 导图的兄弟节点纵向排列、子层横向展开；C 的图片区作用范围限于内容区。
- B 收起线索后，桌面线索列从约 214 像素缩至 104 像素，正文获得更多空间。
- C 在 1440 × 1000 窗口中，正文底部与固定总结顶部保持 12 像素间隔；390 × 844 窄窗口中，总结回到文档流。两种情况均未覆盖正文或造成页面级横向溢出。
- 直接以本地文件打开 HTML 时，布局切换和 URL 参数更新仍可运行。
- A 新增笔记本栏展开/收起按钮。1440 像素窗口下收起后笔记区域从 1125 像素增至 1393 像素；760 像素窗口默认收起，展开及再次收起均可操作。标题和正文草稿保留，收起操作没有重建正文编辑元素；键盘焦点回到当前可见的切换按钮，切换其他布局再返回也保留侧栏状态。

这些操作由浏览器 DOM、输入事件和页面状态观测完成；没有引入正式测试套件。截图和观察脚本保留在本地原型工作区外。

## 仍需实际反馈或后续验证

- 用户选择布局、分区比例、折叠方式、插入方式，以及导图展开编辑是否顺手。
- 用户确认线索区和总结区的编辑能力，以及是否需要 Markdown 源码模式。
- 真实系统剪贴板的截图、网页、Office 和文件复制来源。当前图片粘贴观察使用模拟事件，没有改动用户系统剪贴板。
- 中文输入法、跨组件撤销、生产编辑器 Markdown 兼容性、保存恢复、macOS 及实际桌面壳。

最终产品决策仍保持开放，原型能运行不等于用户已认可方案。
